# Code of conduct

Treat contributors and users respectfully. Critique code and ideas constructively.
Harassment, discrimination, threats, doxxing and unwanted sexual attention are
not acceptable in issues, pull requests or other project spaces.

Protect personal fitness data and credentials. Use synthetic examples and the
private process in [SECURITY.md](SECURITY.md) for vulnerability details.

For conduct concerns, ask the maintainer for a private channel without posting
sensitive details. The maintainer may remove content, close conversations or
restrict participation, proportionate to the behavior. Apply these expectations
consistently and allow affected people to explain their perspective privately.
