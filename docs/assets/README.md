# RepBridge brand asset

`repbridge-reversed.png` is the owner-selected reversed logo: a white bridge
symbol and RepBridge wordmark on charcoal. It was prepared with OpenAI image
generation from the approved project concept. It is project artwork distributed
under the repository's Apache-2.0 terms; it is not a Garmin or OpenAI mark.

Keep the symbol, wordmark proportions and padding together. The README uses a
640-pixel display width. This raster lockup is intended for headers, not as a
16-pixel favicon; do not claim a separate small-icon asset has been validated.
