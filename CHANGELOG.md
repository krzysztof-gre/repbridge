# Changelog

The first public version is **0.1.0**. Every subsequent merge to protected `main`
publishes a SemVer release with changes generated from Conventional Commits.

See [GitHub Releases](https://github.com/krzysztof-gre/repbridge/releases) for the
version-by-version changelog, source archives, checksums and container references.

## Initial capabilities

- Garmin Connect MCP tools with server-enforced IAM-style permissions.
- Native workout creation/editing, scheduling and queued watch delivery.
- Browser sign-in, encrypted sessions and automatic token refresh.
- Docker setup, local stdio, authenticated HTTP and OpenAI gateway integration.
- Conservative starter policy, response projection and trusted resource guards.
